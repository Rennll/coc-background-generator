# CoC 7e 調查員背景產生器

純前端的《克蘇魯的呼喚》第七版調查員背景產生器。使用原生 HTML、CSS、JavaScript，不需要後端或帳號。

## 本機執行

需要 Node.js 18+（只用於執行測試）及 Python 3（用於啟動靜態伺服器）。在專案根目錄執行：

```bash
python -m http.server 8000
```

瀏覽器開啟 http://localhost:8000 。請勿直接雙擊 `index.html`，因為瀏覽器會限制載入 JSON 資料。

## 測試

```bash
npm test
```

## 功能

- 逐題問卷與條件分支
- 背景預覽、編輯、複製及 JSON 匯出
- 不自動儲存，不收集個人資料
