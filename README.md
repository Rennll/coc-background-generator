# CoC 7e 調查員背景產生器

《克蘇魯的呼喚》第七版調查員背景產生器的純前端原型，使用原生 HTML、CSS、JavaScript，不需要後端或帳號。

## 開啟方式

目前原型集中在 `index.html`，可直接在瀏覽器開啟；若瀏覽器限制剪貼簿功能，複製按鈕會提供手動複製文字的替代方式。

## 目前功能

- 11 個問卷步驟
- 背景欄位可編輯
- 複製完整背景文字
- 匯出 JSON
- 重新產生前會確認
- 不自動儲存

## 開發狀態與限制

這是放上 GitHub 供持續開發的初步原型，不是規格書的完整實作。現階段問卷文案與分支是暫用版本，尚未逐題對照 Notion 規格書；職業清單、官方來源與繁中譯名也尚未完成核對。瀏覽器端到端操作測試尚未完成。
