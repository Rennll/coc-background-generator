# CoC 7e 調查員背景產生器

透過問卷建立《克蘇魯的呼喚》第七版調查員背景草稿，並可編輯、複製或匯出角色資料。

## 功能

- 依回答顯示條件題，產生八個背景欄位：外貌描述、信念、重要之人、珍貴之物、恐懼與擔憂、個性、有意義的地點、與調查的連結。
- 編輯五個基本資料欄位：姓名、職業、年齡、出生地、居住地。
- 使用台灣漢人、日本或 1920 年代美國姓名文化產生候選姓名，或從職業清單選擇職業。
- 複製完整背景、複製單一欄位，或匯出角色 JSON。
- 問卷進度與角色草稿會保存在目前瀏覽器，重新整理後可恢復。

## 限制

- 純靜態網站，不需要帳號、後端、AI 或資料庫。
- 本機保存不會跨裝置或瀏覽器同步；重要角色請匯出 JSON 備份。
- 職業清單的繁體中文是專案工作譯名，並非已核實的官方繁中譯名；職業是否適用於 1920 年代也尚未逐項確認。
- 產生內容是可編輯的背景草稿，不包含角色屬性、技能或遊戲中資料。
- JSON 是本專案自訂格式，並非 Chaosium 官方 JSON 標準。
- 需透過 HTTP 靜態伺服器開啟；直接雙擊 `index.html` 可能無法載入資料。

## 線上使用

已部署的 GitHub Pages 網站：[開啟 CoC 7e 調查員背景產生器](https://rennll.github.io/coc-background-generator/)。

## 本機開啟方式

在專案目錄執行：

```bash
python -m http.server 8000
```

再以瀏覽器開啟 http://localhost:8000。

完整功能規格與驗收條件請見 [docs/spec.md](docs/spec.md)。
