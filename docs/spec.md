# 功能規格

本文件是 CoC 7e 調查員背景產生器的正式功能規格。已實作行為以此文件為準；自動化測試負責驗證可測試的規則，人工驗收則補足文字品質與實際裝置體驗。

## 1. 產品範圍

- 以問卷答案產生《克蘇魯的呼喚》（Call of Cthulhu）第七版調查員背景草稿。
- 使用者可以編輯角色基本資料與生成的背景文字，並複製或匯出結果。
- 網站是純前端靜態網站，不需要帳號、後端服務、AI 或資料庫。
- 本工具產生的是背景草稿，不負責建立或計算角色屬性、技能、理智值等遊戲數值。

## 2. 問卷與背景生成

- 問卷題目及選項以資料檔定義；題目與選項 ID 是穩定識別碼，流程邏輯不得依賴顯示文字或選項順序。
- 問卷依回答顯示條件題。當使用者修改前置答案，所有因此失效的後續答案都必須清除；仍有效的答案應保留。
- Q3a/Q3b、Q4/Q5、Q6/Q7、Q10/Q11 為條件分支。Q10 可選擇自訂職業；選擇自訂職業時必須輸入非空白職業名稱，該名稱會帶入角色職業欄位。Q10 同時決定 Q11 的選項分支。
- 問卷完成後產生八個背景欄位：外貌描述、信念、重要之人、珍貴之物、恐懼與擔憂、個性、有意義的地點、與調查的連結。
- 背景文字依模板組合答案。沒有可用內容的欄位保持空白，不得產生「undefined」「null」或只有殘缺前綴的文字。
- 條件分支及模板規則必須與題目資料一致；無效答案或不完整的必要輸入應明確報錯，不得靜默產生錯誤內容。

## 3. 預覽與編輯

- 預覽固定顯示五個基本資料欄位：姓名、職業、年齡、出生地、居住地，以及八個背景欄位；即使欄位尚未填寫，也要保留欄位及編輯入口。
- 使用者可點擊欄位文字或編輯按鈕編輯單一欄位，並選擇儲存或取消。編輯一個欄位不得改動其他欄位。
- 年齡只接受非負整數或空白；空白匯出為 JSON `null`。
- 職業編輯提供兩種互斥模式：從既有分類列表選擇，或在獨立輸入欄自行填寫。列表中原本合併呈現的不同職業已拆成獨立選項；同一職業的譯名差異仍不會被當成新職業。自訂模式啟用時，自訂名稱會取代列表職業；儲存後，畫面、複製文字與 JSON 都以最後職業欄位為準。切換模式不會修改職業資料庫。列表只顯示繁中工作譯名與英文原名；手冊標籤、別名、交叉參照、來源及核實狀態保留於資料層。繁體中文名稱不宣稱為官方譯名；1920 年代適用性未逐項核實前，不得視為已完成歷史核實。
- 姓名編輯器提供台灣漢人、日本與 1920 年代美國姓名文化的候選姓名。台灣漢人與日本姓名採姓氏在前，美國姓名採 GivenName Surname（名在前、姓在後並以空格分隔）。使用者可以重新抽取、取消或確認套用；選擇姓名文化後應立即更新候選。確認套用後姓名直接保存，不需要再按一次欄位儲存。姓名分類標籤應保留在姓名欄位旁。姓名素材供遊戲氣氛使用，並非逐筆史料核實的歷史姓名資料庫。

## 4. 複製、匯出與重設

- 「複製完整背景」複製已填寫的基本資料與背景欄位文字；「複製欄位」只複製該欄位內容。已知職業在複製文字中以「繁中名稱（English Name）」顯示；自訂職業保留原輸入。
- JSON 匯出使用本專案自訂的版本 2 格式，包含 `version`、`meta`、六個 `profile` 欄位及八個 `background` 欄位。`profile.occupation` 保存繁中職業名稱，`profile.occupation_en` 保存已知職業的英文原名；自訂職業的英文欄位為空字串。它不是 Chaosium 官方 JSON 標準。
- JSON 不得包含原始問卷答案、角色屬性、技能或遊戲進行中資料。
- 重新產生前必須顯示確認。取消時保留目前問卷／角色與手動編輯；確認後清除本機保存的問卷進度與角色草稿，並回到問卷起點。

## 5. 本機保存與資料載入

- 問卷答案、目前步驟、角色草稿、姓名分類及姓名文化設定會自動保存至目前瀏覽器的 `localStorage`。
- 重新整理後應恢復問卷進度或已生成的角色；恢復時須驗證已保存的答案，清除不再有效的分支答案，並將步驟限制在有效流程範圍內。
- 保存資料僅限同一瀏覽器與網站來源，不會跨裝置或瀏覽器同步。瀏覽器可能限制或清除本機資料；重要角色應匯出 JSON 備份。
- 初始互動畫面只需要載入 `questions.json`。背景模板於生成背景或恢復角色時載入；姓名資料於開啟姓名編輯器時載入；職業資料於編輯職業欄位時載入。
- 問卷／背景生成的純商業邏輯不得直接操作 DOM、瀏覽器 API 或儲存；瀏覽器副作用由介面／服務層處理。

## 6. 開啟方式與限制

- 網站需透過本機或遠端 HTTP 靜態伺服器開啟；直接以 `file://` 雙擊 `index.html` 可能因瀏覽器限制而無法載入 JSON。
- 本工具不提供雲端同步、帳號或伺服器端備份。
- 自動化測試與響應式檢查不能取代真人的敘事品質審閱，也不等同於已完成所有實體手機的觸控驗收。

## 7. 驗收條件

- 問卷依條件顯示題目；修改前置答案會清除失效的子題答案並保留有效答案。
- 完成問卷後，八個背景欄位與五個基本資料欄位都顯示，空白欄位仍可編輯。
- 儲存、取消及單欄編輯符合預期；姓名確認後立即套用。
- 複製功能取得正確內容；JSON 欄位符合白名單、年齡與時間戳記驗證規則。
- 重新整理可恢復問卷／角色草稿；重新產生的取消保留資料，確認則清除本機保存並重設流程。
- 首次載入只要求問卷資料，其他資料在相應功能需要時才載入。
- 職業列表將「士兵（Soldier）」與「海軍陸戰隊員（Marine）」分開列出；職業自訂模式可覆蓋列表選擇，並保持預覽與匯出一致。
- 自動化測試通過；未經實際驗證的人工敘事審閱或實體裝置測試不得標記為已完成。
